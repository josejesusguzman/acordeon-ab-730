# Ejercicio: de cero a una presentación terminada

**Objetivo:** recorrer el flujo completo —investigar, redactar, estructurar, presentar y comunicar— usando Copilot en cuatro aplicaciones. Tiempo estimado: 45 minutos.

**Escenario:** tienes que presentar el próximo martes al comité directivo una propuesta para adoptar IA generativa en tu área. No tienes nada escrito.

---

## Fase 1 — Investigar (10 min)

**En Copilot Chat, modo Web:**
```
Investiga cómo están adoptando IA generativa las áreas de [tu área: finanzas /
operaciones / RH] en empresas medianas. Dame los tres casos de uso más comunes,
los dos obstáculos que más se reportan y qué métricas se usan para medir el
resultado. Cita las fuentes.
```

**Cambia a modo Trabajo:**
```
Busca en mis documentos y correos del último año menciones a procesos manuales,
retrabajos o cuellos de botella en mi área. Agrúpalos por proceso.
```

> [!TIP]
> Este segundo prompt es el que hace la diferencia frente a cualquier presentación genérica descargada de internet: aterriza el tema en los dolores reales de tu organización.

**Guarda la salida de ambos.** La vas a necesitar en la fase 2.

---

## Fase 2 — Redactar el documento base en Word (15 min)

1. Abre Word → icono de Copilot → panel de chat.

2. **Estructura primero:**
   ```
   Voy a proponer al comité directivo la adopción de IA generativa en mi área.
   Dame el índice de un documento de cuatro páginas que convenza a un comité
   escéptico: qué secciones debe tener y qué debe demostrar cada una.
   ```

3. **Contenido sección por sección** (no todo de golpe):
   ```
   Escribe la sección "Situación actual" usando estos hallazgos: [pega el
   resultado del modo Trabajo]. Tono directo, sin adjetivos. Máximo 200 palabras.
   ```

4. **Convierte los datos en tabla:**
   ```
   Convierte los casos de uso en una tabla con columnas: Proceso, Tiempo actual,
   Intervención propuesta, Métrica de éxito.
   ```
   Refina:
   ```
   Agrega fila de encabezado y pon los títulos en negrita.
   ```

5. **Revisa el tono:**
   ```
   Revisa todo el documento y señala las tres frases que un director financiero
   consideraría poco sustentadas. No las reescribas, solo señálalas.
   ```

6. **Corrige tú esas tres frases.** Guarda como `Propuesta-IA.docx`.

---

## Fase 3 — Construir la presentación en PowerPoint (10 min)

1. Abre PowerPoint → icono de Copilot.

2. Referencia el documento:
   ```
   /Propuesta-IA.docx
   ```

3. Genera la base:
   ```
   Crea una presentación de 8 diapositivas a partir de este documento para un
   comité directivo. Estructura: problema, evidencia interna, propuesta,
   casos de uso, riesgos y mitigación, costo, métricas, decisión que pido hoy.
   ```

4. Afina:
   ```
   Haz que las viñetas sean concisas y orientadas a la acción, máximo una línea
   cada una.
   ```
   ```
   La diapositiva final debe tener una sola pregunta clara: qué necesito que
   aprueben.
   ```

5. **Ajusta a mano lo visual:** plantilla corporativa, logotipo, imágenes.

---

## Fase 4 — Comunicar en Outlook (10 min)

1. **Resume el contexto previo:**
   ```
   Resume el hilo de correo con [nombre del director] sobre presupuesto del
   trimestre y dime qué objeciones ha planteado antes.
   ```

2. **Redacta la convocatoria:**
   ```
   Escribe un correo para convocar al comité del martes. Adjunto la presentación.
   Máximo 100 palabras, con una línea que anticipe la decisión que voy a pedir.
   Tono profesional y cordial.
   ```

3. **Anticipa el contraataque:**
   ```
   Eres el director financiero del comité. Dame las cinco preguntas más duras que
   le harías a esta propuesta y qué evidencia pedirías para cada una.
   ```

   Prepara esas cinco respuestas. Este paso es opcional en el curso y obligatorio en la vida real.

---

## Lista de verificación final

- [ ] ¿Cada cifra del documento tiene una fuente que puedo abrir?
- [ ] ¿La apertura y el cierre están escritos con mi voz, no con la de Copilot?
- [ ] ¿La última diapositiva pide algo concreto?
- [ ] ¿Preparé respuestas para las cinco preguntas difíciles?
- [ ] ¿Revisé que no se haya colado información confidencial que no deba circular?

> [!NOTE]
> Cronometra cuánto tardaste. Compáralo honestamente con lo que te habría tomado a mano. Ese número es tu caso de negocio personal.
