# Práctica 2: Encargo de investigación con el agente Investigador
**Objetivo:** Usar el agente Investigador de forma eficiente y evaluar críticamente su salida.

> [!IMPORTANT]
> Cada consulta cuenta contra tu límite de **25 mensuales combinadas** con el agente Analista. Diseña el encargo antes de escribirlo.

## Paso a Paso:

1. **Escribe el encargo en papel primero.** Usa la plantilla:
   ```
   TEMA:
   ALCANCE (periodo, geografía, sector):
   FUENTES (internas y externas):
   ENTREGABLE (secciones exactas):
   CRITERIO de utilidad:
   ```

2. **Revísalo con Copilot Chat gratis antes de gastar la consulta:**
   ```
   Voy a darle este encargo a un agente de investigación. Antes de enviarlo,
   dime qué está ambiguo, qué le falta y cómo lo reescribirías:
   [pega tu encargo]
   ```

3. **Ahora sí, ejecútalo** en Agentes → Investigador.

4. **Responde con detalle sus preguntas aclaratorias.** No contestes "como tú veas": cada respuesta vaga te va a costar un refinamiento.

5. **Audita la salida con esta rúbrica:**

   | Criterio | ✅/❌ | Nota |
   |---|---|---|
   | ¿Todas las afirmaciones importantes tienen cita? | | |
   | ¿Abrí al menos tres citas y respaldaban lo dicho? | | |
   | ¿Distingue entre lo interno y lo externo? | | |
   | ¿Menciona limitaciones o incertidumbre? | | |
   | ¿Hay algo que contradice lo que yo sé del negocio? | | |

6. **Refina una sola vez**, con el hueco más grande que encontraste:
   ```
   Resalta los riesgos o desafíos del mercado.
   ```

7. **Reformatea para tu entregable real:**
   ```
   Escribe un resumen ejecutivo de este informe.
   ```
   o
   ```
   Resume esto en tres viñetas para una diapositiva de liderazgo.
   ```

8. **Registra el costo.** Anota cuántas consultas usaste de las 25 y si el resultado justificó el gasto.

## Qué debiste aprender

- Un encargo bien diseñado consume una consulta; uno improvisado consume cuatro.
- La utilidad del informe se mide por cuántas de sus citas resisten que las abras.
- Copilot Chat gratuito es el mejor lugar para *preparar* el encargo que le vas a dar al agente de pago.
