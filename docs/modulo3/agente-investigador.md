# El agente Investigador (*Researcher*) a fondo

## 1. Qué es y qué no es

**Es:** un agente de razonamiento que hace investigación **en varios pasos**, combinando tu contenido de trabajo con orígenes web públicos, y entrega informes estructurados con citas.

**No es:** un buscador más rápido. Si lo que quieres es encontrar un archivo, usa la búsqueda; si quieres redactar un correo, usa Copilot Chat. El Investigador se justifica cuando la pregunta requiere **reunir, contrastar y sintetizar** información de varias fuentes.

| | **Copilot Chat estándar** | **Agente Investigador** |
|---|---|---|
| Optimizado para | Redacción y edición | Detección, síntesis y generación de información |
| Profundidad | Una pasada | Investigación multipaso |
| Preguntas aclaratorias | Rara vez | Sí, antes de trabajar |
| Salida | Respuesta conversacional | Informe estructurado con citas |
| Costo | Ilimitado | Cuenta contra las **25 consultas mensuales** |

## 2. Acceso y límites

- **Licencia requerida:** Microsoft 365 Copilot.
- **Dónde:** [microsoft365.com](https://www.microsoft365.com) o la app de escritorio → sección **Agentes** → **Investigador**.
- **Límite:** **25 consultas combinadas al mes** entre Investigador y Analista.

> [!WARNING]
> El límite es mensual y compartido entre los dos agentes. Gastar cinco consultas en preguntas que Copilot Chat resolvía gratis es el error más común del primer mes.

## 3. Flujo de trabajo completo

### Paso 1 — Abre el agente
Copilot Chat → Agentes → **Investigador**.

### Paso 2 — Escribe el encargo inicial
Sé ambicioso: este agente está hecho para preguntas grandes.
```
Investiga las últimas tendencias de IA para minoristas y redacta un informe de
análisis de mercado basado en datos de la competencia.
```

### Paso 3 — Responde sus preguntas aclaratorias
El agente puede preguntarte el alcance, el periodo, el mercado geográfico o el formato. **Contéstale con detalle**: cada aclaración que das aquí te ahorra una consulta de refinamiento después.

### Paso 4 — Revisa la salida
Verifica el informe estructurado: resúmenes, citas y vínculos a los archivos de origen.

### Paso 5 — Refina el alcance
```
Incluye información sobre comportamiento del consumidor y tasas de adopción.
```
```
Resume los movimientos clave de los principales competidores en los últimos 12 meses.
```
```
Resalta los riesgos o desafíos del mercado.
```

### Paso 6 — Elige el formato de salida
```
Resume esto en tres viñetas para una diapositiva de liderazgo.
```
```
Escribe un resumen ejecutivo para este informe.
```
```
Redacta una actualización por correo que resuma estos resultados.
```

## 4. Cuándo vale la pena gastar una consulta

✅ **Sí:**
- Preparas una sesión de estrategia y necesitas panorama de mercado.
- Respondes a una solicitud de dirección que exige contrastar lo interno con lo externo.
- Necesitas un análisis competitivo con fuentes verificables.
- Vas a tomar una decisión donde el costo de equivocarte supera con mucho el valor de una consulta.

❌ **No:**
- Resumir un documento que ya tienes.
- Redactar un correo.
- Buscar un archivo.
- Preguntas que se contestan con una búsqueda de treinta segundos.

## 5. Cómo escribir un buen encargo de investigación

La plantilla que funciona:

```
TEMA: qué quiero entender
ALCANCE: periodo, geografía, sector, tamaño de empresa
FUENTES: usa mis documentos internos sobre [X] y además fuentes públicas recientes
ENTREGABLE: informe de N secciones con estas secciones específicas
CRITERIO: qué haría que este informe me sirva de verdad
```

Ejemplo completo:
```
TEMA: adopción de agentes de IA en centros de contacto.
ALCANCE: últimos 18 meses, empresas medianas en México y Latinoamérica.
FUENTES: mis documentos internos sobre nuestro centro de contacto, más informes
públicos y notas de industria.
ENTREGABLE: informe con cuatro secciones — estado del arte, qué hacen los
competidores, qué tenemos nosotros, brechas y recomendaciones.
CRITERIO: me sirve si puedo llevarlo a un comité y defender cada afirmación
con su fuente.
```

## 6. Regla de oro

> Un informe del Investigador es un **punto de partida documentado**, no una conclusión. Las citas existen para que las abras, no para que decoren el documento.
