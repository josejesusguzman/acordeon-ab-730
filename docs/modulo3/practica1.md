# Práctica 1: Un mismo contenido, cuatro formatos
**Objetivo:** Practicar la transformación de contenido entre Word, PowerPoint y Outlook sin volver a escribir desde cero.

## Paso a Paso:

1. **Elige un documento real** que ya tengas: un informe, una minuta larga o una propuesta. Guárdalo en OneDrive.

2. **Formato 1 — el resumen ejecutivo.** En Word, con Copilot:
   ```
   Resume este documento en un resumen ejecutivo de máximo 150 palabras para
   alguien que no conoce el contexto. Empieza por la conclusión.
   ```

3. **Formato 2 — la tabla.** Selecciona la sección con datos y pide:
   ```
   Convierte esta sección en una tabla con columnas [define tus columnas].
   ```
   Refina:
   ```
   Agrega fila de encabezado, pon los títulos en negrita y ordena de mayor a menor.
   ```

4. **Formato 3 — la presentación.** En PowerPoint, referencia el documento con `/` y pide:
   ```
   Crea seis diapositivas a partir de /[tu documento]. Una idea por diapositiva,
   viñetas de una línea, orientadas a la acción.
   ```

5. **Formato 4 — el correo.** En Outlook:
   ```
   Redacta un correo de tres párrafos que comunique lo esencial de este documento
   a alguien que no va a abrir el adjunto. Profesional y conciso.
   ```

6. **Compara los cuatro** y responde: ¿cuál requirió más edición manual y por qué?

7. **Prueba la diferencia trabajo/web.** Pídele a Copilot que enriquezca tu documento primero con datos internos:
   ```
   Resume la información interna reciente sobre [tema del documento] de mis
   documentos y correos.
   ```
   y luego con datos públicos:
   ```
   Resume las tendencias actuales de [tema] usando orígenes web recientes.
   ```
   Anota cuál aportó más y por qué.

## Qué debiste aprender

- Transformar es más barato y más fiel que volver a generar.
- El formato que más edición requiere casi siempre es la presentación, porque lo visual no se resuelve con texto.
- Combinar contexto interno con referencia externa produce contenido más difícil de refutar.
