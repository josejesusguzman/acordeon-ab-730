# Práctica 1: El ciclo completo de una reunión
**Objetivo:** Usar Copilot antes, durante y después de una reunión real, y medir cuánto trabajo manual desaparece.

## Paso a Paso:

### Antes de la reunión (Outlook)

1. **Ponte al día del contexto:**
   ```
   Resume este hilo de correo sobre [tema] y dime qué se decidió, qué quedó
   pendiente y qué desacuerdos siguen abiertos.
   ```

2. **Genera la agenda:**
   ```
   Con base en ese resumen, crea una agenda de 30 minutos con tiempos por punto.
   Marca cuáles requieren decisión y cuáles son informativos.
   ```

3. **Bloquea tu preparación:**
   ```
   Muestra mis reuniones de hoy y bloquea 30 minutos de trabajo concentrado antes
   de la reunión de [nombre].
   ```

### Durante la reunión (Teams)

4. **Configura antes de iniciar.** Opciones de reunión → **Permitir Copilot** → decide:
   - *Durante y después* (requiere transcripción) — para reuniones de trabajo normales.
   - *Solo durante* — para temas sensibles.

   Habilita transcripción y grabación en la nube si elegiste la primera.

5. **Avisa a los participantes** que se está transcribiendo. No es un formalismo: en varias jurisdicciones es obligatorio.

6. **Prueba estos prompts en vivo:**
   ```
   ¿Cuáles son las principales ventajas hasta ahora?
   ```
   ```
   ¿Dónde no estamos de acuerdo?
   ```
   ```
   Crea una tabla de ventajas y desventajas para cada idea.
   ```
   ```
   Dime lo que me perdí hasta ahora.
   ```

### Después de la reunión

7. **Abre el resumen:** pestaña **Resumen** en el chat de la reunión → **Copilot**. Verifica que incluya citas y atribución.

8. **Genera los pendientes:**
   ```
   Enumera los pendientes de la transcripción para cada miembro del equipo.
   ```

9. **Redacta el seguimiento:**
   ```
   Redacta un correo de seguimiento que resuma las decisiones de hoy y los pasos
   siguientes. Tono profesional, máximo 150 palabras, con la tabla de pendientes.
   ```

10. **Exporta** el resumen a Word o Excel si lo necesitas como registro.

11. **Mide.** Anota cuánto tiempo te habría tomado hacer minuta y seguimiento a mano.

    | Tarea | Tiempo manual estimado | Tiempo con Copilot |
    |---|---|---|
    | Ponerse al día del hilo | | |
    | Armar agenda | | |
    | Redactar minuta | | |
    | Distribuir pendientes | | |

## Qué debiste aprender

- Sin transcripción, Copilot solo ve el chat. Es la variable que más cambia la calidad del resultado.
- El resumen con citas y atribución es lo que lo hace defendible frente al equipo.
- El mayor ahorro no está en la minuta: está en **ponerse al día antes** de la reunión.
