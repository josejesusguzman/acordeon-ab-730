# Práctica 2: Cuaderno de proyecto y página compartida
**Objetivo:** Montar el espacio de trabajo de un proyecto real con Cuadernos y Páginas, y comprobar sus límites.

## Paso a Paso:

### Parte A — El cuaderno

1. **Crea el cuaderno** con el nombre real de un proyecto activo.

2. **Agrega referencias en dos tandas.** Primero cinco documentos clave. Haz una pregunta. Luego agrega diez más y repite la misma pregunta.
   ```
   ¿Cuál es el estado actual del proyecto según estos documentos y qué compromisos
   tenemos con quién?
   ```
   **Compara las dos respuestas.** ¿Mejoró o se diluyó? Esta es la lección práctica del límite de 20 referencias.

3. **Fija instrucciones personalizadas:**
   ```
   Responde de forma profesional y con viñetas. Cita siempre el documento del que
   sale cada afirmación. Si algo no está en las referencias, dilo explícitamente
   en vez de suponer.
   ```

4. **Haz la pregunta que más valor da:**
   ```
   ¿Qué contradicciones o vacíos hay entre estos documentos?
   ```

5. **Prueba un límite a propósito:** intenta agregar un vínculo web como referencia. Confirma que no se soporta y anótalo.

6. **Genera la introducción de audio** en español y escúchala.

### Parte B — La página

7. **En Copilot Chat**, pide:
   ```
   Crea una página de planeación colaborativa para [proyecto] con secciones de
   objetivos, hitos con línea de tiempo, roles y responsabilidades, y riesgos
   abiertos. Deja marcadores de posición para la entrada del equipo.
   ```

8. **Icono Páginas → Editar en Páginas.**

9. **Agrega dos respuestas más** del chat a la misma página.

10. **Comparte de las dos formas** y observa la diferencia:
    - **Vínculo de página** a un colega.
    - **Copiar el componente** dentro de un chat de Teams.

11. **Pide a alguien que edite** y revisa el rastreo de cambios: foto de perfil, "+N", detalle al pasar el puntero.

12. **Convierte a Word** y anota qué se conservó y qué se perdió en la conversión.

## Qué debiste aprender

- Más referencias no es mejor: **20 bien curadas** superan a cincuenta revueltas.
- Los cuadernos son mejores detectando **contradicciones** entre fuentes que resumiendo cada una.
- El componente Loop mantiene el contenido vivo dentro del chat; el vínculo manda a la gente a otro lado. Elige según qué tan probable es que vuelvan a mirarlo.
